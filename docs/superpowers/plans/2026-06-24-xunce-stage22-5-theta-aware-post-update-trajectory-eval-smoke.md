# Stage22.5 Theta-Aware Post-Update Trajectory Eval Smoke

## Goal

Stage22.5 verifies whether the Stage22.4 theta-aware experimental checkpoint
starts to change real offline trajectory choices over `(x,y,theta)` viewpoint
actions. It wraps Stage21.5 and does not reimplement trajectory evaluation.

## Audit Contract

The wrapper must read pre/post `xunce-exploration-coverage-model-inference.jsonl`
and compare only rows joined by:

```text
scenario_id + step_index + current_cell + covered_cells_hash + candidate_set_hash
```

It records selected viewpoint changes, selected theta changes, selected action
changes, mean probability delta, final coverage delta, coverage AUC delta,
path-cost delta, hard-risk/mask/path-planning/open-grid regressions, and whether
the sample count is too small for a performance claim.

## Routing

- Input missing or Stage22.4 not passed:
  `rerun_stage22_5_required_inputs`
- Theta inference fields missing or strong join unavailable:
  `repair_stage22_5_theta_inference_binding`
- Safety regression:
  `repair_stage22_5_theta_eval_safety_regression`
- Action probabilities and viewpoint unchanged:
  `repair_stage22_theta_policy_update_signal_strength`
- Viewpoint changed but coverage/AUC did not improve or a scenario regressed:
  `repair_stage22_theta_credit_assignment`
- Coverage/AUC improved and worst scenario did not regress:
  `run_stage22_6_theta_aware_multi_seed_ppo_pilot`

## Non-Goals

Stage22.5 does not publish checkpoints, replace the default policy, connect an
executor, start canary traffic, introduce continuous theta policy, modify the
network, modify default A*, or claim production performance. It is a bounded
offline smoke.
